# ВОПРЕКИ

Психологическая 3D-игра в стиле PlayStation 1 о двух людях, которые долго боролись друг с другом, хотя оба хотели одного и того же.

> Мы не обязаны побеждать друг друга. Иногда нужно просто перестать бороться и продолжить идти вместе.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка:

```bash
npm run build          # dist/ — обычная статическая сборка
npm run build:single   # dist-single/index.html — вся игра в одном HTML-файле
```

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | камера вокруг героя (клик по экрану захватывает курсор, Esc отпускает; можно и тянуть мышью с зажатой кнопкой) |
| W / ↑ | идти от камеры |
| S / ↓ | идти к камере |
| A D / ← → | идти влево / вправо (в автобусе — поворот головы, как и мышью) |
| Shift | бежать |
| E / Пробел / Enter | действие, далее |
| Esc | пауза (настройки, полный экран, выход в меню) |
| J / K | удар / защита (финальная битва) |
| F | «страшное лицо» (глава 4) |
| Q (удерживать) | дыхание (глава 8) |

Прогресс сохраняется автоматически (localStorage): «Продолжить» и «Главы» в главном меню.

## Структура истории

| # | Глава | Механика |
|---|---|---|
| Пролог | Сон | комната, засыпание, первое преследование, осколки воспоминаний |
| 1 | Автобус № 77 | ожидание на остановке под дождём, кат-сцена первого взгляда, украдкой брошенные взгляды (поворот головы) |
| 2 | Сообщение | кошмарный лабиринт → телефон: лайки, профиль, она пишет первой, ответ |
| 3 | Первое свидание | прогулка рядом (она подстраивается под шаг), поздняя смена на складе игрушек (коробки на стеллажи + переписка), первый поцелуй вечером у пруда на лавке |
| 4 | Вместе | кошмар → переезд и коробки → снежный ноябрь у пруда: «Ты всё равно от меня не убежишь!» и погоня вокруг пруда (она уворачивается, дыхание героя) |
| 5 | Папаша | «Поздравляю, папаша» (dolly-zoom), ссора с руганью и разбитой тарелкой, выбор примирения, роддом |
| 6 | Семья | кошмар (реальное время на часах игрока) → ночное укачивание → прогулка на одинокой детской площадке |
| 7 | Второй | второй сын, слова старых обид на стенах, ссора с разбитой чашкой, разговоры по душам, перемирие, надежда |
| 8 | Внутри | бесконечный коридор, сломанное время, дыхание; она пытается понять → последнее преследование (фальшивый «сбой» игры) |
| Финал | Зеркало | противник повторяет каждое действие; последнее воспоминание в автобусе; объятие и PS1-трансформация; распад мира; дорога под дождём, дети, один шаг |

Разрушение четвёртой стены нарастает постепенно: сообщения автосохранения, реальное время игрока, пункт «Перестать бежать» в меню паузы, смена заголовка вкладки, имитация зависания программы, счётчик минут игры, поменявшиеся местами имена в битве.

## Технологии

- **Three.js** + **Vite**, чистый JavaScript.
- PS1-рендер (`src/engine/ps1.js`): низкое внутреннее разрешение (240 строк), привязка вершин к пиксельной сетке, 15-битный цвет с упорядоченным дизерингом, ЭЛТ/VHS-эффекты, туман.
- Все текстуры процедурные (`src/engine/textures.js`), никаких внешних картинок.
- Все модели — собственные low-poly (`src/engine/character.js`, `src/world/`), лица — пиксельные текстуры с эмоциями.
- **Вся музыка и звуки синтезируются в реальном времени** (`src/engine/audio.js`): оригинальная фортепианная тема (си минор / ре мажор, Bm–G–D–A), которая в финале перерастает в оркестр (струнные, медь, литавры, хор).

## Что настраивается

- `src/config/family.js` — внешность и одежда персонажей (по присланному концепт-листу).
- `src/config/story.js` — реплики, которых не было в исходном описании (первое сообщение, ответы и т. п.). **Их стоит заменить настоящими словами.**

## Что требует согласования

- Точные тексты переписки (глава 2) и слова в бытовых сценах — сейчас нейтральные заглушки.
- Время окончания смены на складе (21:47), «03:12» ночью — условные.
- Рост персонажей, цвет глаз, сторона/тип кольца в носу (сейчас — по центру, как на концепте).
- Внешность детей сделана по концепт-листу; в главе 7 старший сын показан маленьким (около двух лет) — возраст условный.

## Отладка

- `?chapter=N` — запустить с главы N (0 — пролог, 9 — финал).
- `?viewer` — просмотр всех моделей персонажей (`&x=…` — крупный план).
- `?autoplay` — автопилот, который проходит игру (используется для проверки, что все главы проходимы).
