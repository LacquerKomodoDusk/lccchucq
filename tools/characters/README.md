# Персонажи: 3D-модели (low-poly PS1)

Модели строятся **кодом в Blender** (`bpy` — Blender как Python-модуль), поэтому
результат воспроизводим и редактируем.

## Как пересобрать

```bash
python3 -m venv .blenv
.blenv/bin/pip install bpy==5.3.0 pillow      # Blender 5.3 как модуль (~430 МБ)
.blenv/bin/python tools/characters/build_hero.py
```

Можно и в обычном Blender 5.x: `blender -b -P tools/characters/build_hero.py`
(нужен Pillow в его Python).

Превью (нужен запущенный `npx vite preview`):

```bash
node tools/characters/previews.cjs hero assets/characters/hero http://localhost:4173 side walk,sit,hug
```

## Что получается (`assets/characters/hero/`)

| Файл | Что это |
|---|---|
| `hero.glb` | модель glTF 2.0: меш, UV, атлас, скелет, 12 анимаций |
| `hero.blend` | исходник Blender (текстура упакована внутрь) |
| `hero_atlas.png` | пиксельный атлас 256×256 (фильтрация nearest) |
| `hero_atlas_<выражение>.png` | варианты атласа с другим лицом: тревога, боль, усталость, решимость; `young_*` — без бороды |
| `hero_uv.png` | UV-развёртка (прозрачный фон, 1024×1024 для читаемости) |
| `hero_uv_on_atlas.png` | развёртка поверх атласа |
| `hero_front/side/back.png`, `hero_turnaround.png` | превью — рендер настоящей GLB-модели |
| `hero_animations.png` | кадры анимаций (ходьба, сидение, объятие) |

Просмотрщик в браузере: `npm run dev` → `/models.html` (вращение, приближение,
каркас, скелет, атлас с UV, смена лица, все анимации).

## Технические решения

- **Геометрия:** 1 018 треугольников, плоское затенение, один материал.
- **UV — настоящая развёртка, как у выкроек одежды:**
  - швы размечаются по границам «бок / верх / низ» каждой детали и одним
    вертикальным швом сзади (как задний шов на одежде);
  - Blender разворачивает детали методом Angle Based — рукава и штанины
    становятся развёрнутыми полосами, торс и полы тренча — цельными панелями,
    волосы — одним островом;
  - лицо — отдельный закреплённый остров 96×120 px (его не трогает упаковка);
  - Pack Islands раскладывает всё остальное вокруг лица без пересечений,
    с отступами.
- **Текстура рисуется проекцией с 3D-модели** на развёртку: для каждого пикселя
  острова находится точка на модели, и цвет выбирается по её положению —
  поэтому вырез рубашки, пуговицы, ремень, манжеты, подошвы и шнурки стоят на
  своих местах, как бы ни были повёрнуты острова. Лицо и ткани (клетчатый
  тренч, рубашка, джинсы) взяты прямо с утверждённого листа.
- **Риг:** 18 костей (root, hips, spine, chest, neck, head, руки ×3, ноги ×3).
  Привязка жёсткая (вес 1 к одной кости; у пол тренча верх — к тазу, низ — к бедру):
  как в PS1, без искажений при движении.
- **Анимации:** idle, walk, run, turn, look, sit, interact, hug, sleep,
  first_meeting_head_turn, stolen_glance, family_walk.

# Головы (Face production spec v1.0) — все четыре персонажа

```bash
.blenv/bin/python tools/characters/face_expressions.py <лист_лиц.webp>     # лица + эмоции всех четырёх
.blenv/bin/python tools/characters/build_head.py                          # hero wife son_older son_younger
node tools/characters/head_previews.cjs <персонаж> assets/heads/<персонаж> http://localhost:4173
```

Папки `assets/heads/{hero,wife,son_older,son_younger}/`: `head.glb`, `head.blend`,
`face_atlas.png` (+ `face_atlas_<эмоция>.png`), `face_uv.png`, `front.png`,
`side.png`, `three_quarter.png`, `expressions.png`, `head_anim.png`, `views.png`.
Сводные листы: `assets/heads/all_heads_views.png`, `all_heads_expressions.png`.
Просмотрщик: `/heads.html` (персонажи, ракурсы, каркас, скелет, эмоции, шапка, анимации).

- Голова без волос — 392 треугольника у каждого (300–600 по ТЗ). Волосы, борода,
  шапка, кольцо — отдельная геометрия. Шапки жены и младшего сына — отдельные
  съёмные объекты (`wife_hat`, `son_younger_hat`).
- **Единая плотность пикселя:** лица всех четырёх приведены к одной плотности
  (~350 px/м, по жене) и к общей сетке 2×2 px, поэтому пиксель на лице у всех
  одного размера.
- Лицо проецируется по ориентирам текстуры (линия глаз, подбородок, ширина
  лица), поэтому глаза текстуры совпадают с глазницами геометрии.
- Источники лиц: у жены и сыновей — фронтальные текстуры 128×128 с листа; у
  героя фронтальная текстура листа грубая и с чрезмерной бородой, поэтому его
  лицо собрано из крупного портрета (ближняя половина, отзеркалена, перемычка
  между бровями убрана).
- Эмоции (нейтр., удивление, тревога, усталость, грусть, радость) — сменные
  элементы текстуры; у жены ещё «взгляд влево/вправо» для движения глаз.
- Кости `neck`/`head` в позициях скелетов тел (у детей — на их росте).
- Анимации: герой — head_turn_bus, stolen_glance; жена — glance_away
  (быстрое отведение взгляда), stolen_glance; у всех — idle, look_around, nod.
